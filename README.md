## Project Documentation

This project was developed by Tileugabyl Laura for the DevOps Midterm Task.

**Student:** Tileugabyl Laura
**Project:** Student Management CRUD API
**Technologies:** Java, Spring Boot, Gradle, PostgreSQL, Docker, Jenkins

- Create a student
- View all students
- Update student information
- Delete a student

### Project Workflow
1. Develop the Spring Boot application.
2. Store student data in PostgreSQL.
3. Run services using Docker Compose.
4. Automate building and testing using Jenkins.
